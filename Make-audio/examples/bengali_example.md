3. মহাজাগতিক দূরত্ব স্কেল গণনা।

```python
def calculate_deflection(mass: float, radius: float) -> float:
    # 4GM / (c^2 * r)
    return (4 * 6.674e-11 * mass) / ((3e8 ** 2) * radius)
```
